# CampuSphere Test Evidence Checklist

Milestone 8, Section 8.10. Use this checklist to record defense and deployment
evidence without committing private data. Store actual screenshots or recordings
outside the repo unless they have been reviewed and explicitly approved.

## Evidence Rules

- Do not capture real secrets, `.env` contents, private cookies, session IDs,
  Supabase service-role values, OAuth secrets, database passwords, raw logs, or
  private production data.
- Crop or blur browser devtools, request headers, cookies, query strings, and
  terminal output before using evidence in slides or recordings.
- Prefer seeded demo accounts and demo content. If production data is used for a
  live review, document only pass/fail and sanitized notes.
- Keep command evidence to final status lines such as `QUALITY-GATES OK`,
  `DB-PERF-GATE OK`, `IDENTITY-CONSTRAINTS OK`, and `found 0 vulnerabilities`.
